# Hardware

Everything needed to build the physical handheld.

- `case/` — 3D-printable case models (STL/STEP/3MF). Drop your models here.
- `pcb/` — custom PCBs: button boards, breakouts (KiCad/Gerbers).

The button wiring diagram lives in [../docs/button_wiring.svg](../docs/button_wiring.svg)
and the full soldering guide in [../WIRING.md](../WIRING.md).
